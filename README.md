# imobtech-logistica
Landing page estática (HTML/CSS/JS) da ImobTech Logística. Este projeto educacional funciona como um simulador prático de locação e venda de galpões e centros de distribuição, integrando captação real de intenções de negócio. Desenvolvido com fins pedagógicos para demonstração na feira de cursos do curso técnico em Logística do CEET Vasco Coutinho.

# English
Static landing page (HTML/CSS/JS) for ImobTech Logística. This educational project serves as a practical simulator for leasing and selling warehouses and distribution centers, integrating real-time capture of business intentions. Developed for pedagogical purposes to be showcased at the course fair for the Technical Course in Logistics at CEET Vasco Coutinho.
